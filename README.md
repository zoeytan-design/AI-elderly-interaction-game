# 互動窗戶擦拭遊戲 🪟

一個為高齡長輩設計的互動式網頁遊戲，結合手勢識別、記憶訓練，以及 **Gemini AI 自動出題**功能。

## ✨ 功能說明

本遊戲新增 Gemini API 出題功能。每一關會根據窗外圖片與安全標註資料，自動生成適合長輩的觀察記憶題。如果 API 失敗或未設定，會自動使用預設題目，確保遊戲可正常展示。

問答畫面出現後，如果玩家 5 秒內沒有作答且手勢沒有停在任何選項上，旁邊的孫子 / 孫女角色會跳出提示泡泡。

## 🎮 遊戲流程

### Stage 1：擦窗戶 👐
- 用手勢擦掉窗戶上的霧氣（也支援滑鼠）

### Stage 2：倒數記憶 ⏱️
- 在 10 秒倒數內記住窗外場景
- 此時後台已開始向 Gemini 請求本關題目

### Stage 3：問題與答案 ❓
- 顯示 AI 根據圖片生成的觀察記憶題
- 5 秒內未作答且未指向選項時，孫子/孫女會給出提示
- 手勢控制：食指指向按鈕 1.2 秒後自動選擇，或握拳確認

### Stage 4：結果反饋 🏆
- 答對 → 顯示鼓勵文字，進入下一題（重新生成新題目）
- 答錯 → 顯示提示，可再試一次（保留同一題）
